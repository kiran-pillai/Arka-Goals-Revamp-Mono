### Mentions (Story 1)

When @ symbol is used users have the ability to tag other users in their comments.

### UI

When a @ symbol is typed in a comment a dropdown list of users will be shown based on first name + last name. If the user types a word that doesn't correspond to a user the dropdown should disappear. It should be very similar to whatsapp.

### Notifications

1. When users @s a user in a comment they should receive a notification.
2. If user A @s user B in user B's check in, they should only receive one notification that user @ mentioned them.
3. Notification should read like this: user A mentioned you in their comment. Clicking it will take them to the comment.
