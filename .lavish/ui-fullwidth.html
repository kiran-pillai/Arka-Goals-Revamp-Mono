Buttons are equalized

View check-ins moved from size="md" to size="lg" to match, and both now sit in one <Stack gap="sm" mx="auto" maw={320}> with fullWidth — so they share a width instead of each hugging its label. front-end/src/routes/HomeRoute.tsx

3

Check-ins table widened

.checkins-card went from a 1040px cap to the shared 1600px token, giving its six free-text columns noticeably more room. front-end/src/WeeklyCheckIn.css

Decision: full-width with a wide cap — implemented

Content now fills the viewport with padding as the only gutter, capped at 1600px so centered text and the table stay readable on ultra-wide displays. The cap is a single token, --content-max on .squad-screen, so it can be widened or removed in one place.
