Squad Check-ins

Layout A — Card Feed
Layout B — Timeline Feed

Design Proposal Notes

  • Layout A (Card Feed) — Each check-in is an expandable card. Click to reveal the full entry and its comment thread. Best for scanning many entries quickly while allowing deep-dives.
  • Layout B (Timeline) — A vertical timeline with expandable entries. Better chronological feel, good for following a team's week-over-week rhythm.
  • Comments — Threaded under each check-in entry. Visible count on collapsed cards. Input area with a simple send button. Could support @mentions and emoji reactions in a future iteration.
  • Mantine mapping — Cards use Card / Paper, the week separators map to Divider with label, the toggle uses SegmentedControl, badges use Badge, avatars use Avatar, and comment inputs use Textarea + ActionIcon.
  • Dark mode — Toggle in the top-right to preview both themes. All colors adapt, including the Arka amber palette.
  • Mobile — The card layout stacks fields vertically on narrow screens. The timeline collapses gracefully.
  • Avatar colors — A pool of 50 perceptually distinct colors. Each user gets the lowest available slot index; when a user is removed, their slot recycles to the next newcomer. The pool wraps if a squad exceeds 50 members. Colors are assigned at load time, not hashed from the name, so the palette stays clash-free regardless of who joins or leaves.
  • Chosen layout — Layout B (Timeline). Layout A is kept for reference but B is the implementation target.
  • Next steps — Add real-time comment submission, @mention autocomplete, notification badges for new comments, and optional inline replies.
